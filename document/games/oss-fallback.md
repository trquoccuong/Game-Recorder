# Open-source fallback titles

> Status: **fallback** if Odyssey refuses commercial titles (Q12) · Last checked: 2026-10-04
> Back to [games index](./README.md)

These meet spec v3 §5 literally (open source, self-hostable, decodable netcode). The route is an engine patch plus server demos.

| Game | Engine / license | Strength | Note |
|---|---|---|---|
| **Xonotic** | DarkPlaces, GPLv2+ | `sv_autodemo_perclient` server-side per-client demos; re-render at fixed fps | Last stable 0.8.6 (2023); pin an autobuild |
| **Unvanquished** | Daemon, GPL | Team cooperation, building/blocking; maintained (0.55.5, Sep 2025) | Client-side demos only |
| **Red Eclipse 2** | Tesseract, zlib | Best lighting of the OSS set; parkour pursuit | Release cadence unclear |
| **Luanti** (Minetest) | LGPL-2.1 | Server Lua logs every pose per tick; cooperation/building | Voxel look |
| **SuperTuxKart** | GPLv3 | Collision, pursuit, soccer | Third-person camera |
